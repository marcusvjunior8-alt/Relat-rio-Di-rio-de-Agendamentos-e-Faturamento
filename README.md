# 🐾 Patas & Cuidados - Sistema de Gestão e Relatório Diário

Sistema simples desenvolvido em **Python** para controle de atendimento, faturamento e serviços de um pet shop.

## 📋 Sobre o Projeto

Este script interativo via terminal permite que o recepcionista ou atendente registre os pets atendidos ao longo do dia, informando o nome do pet, o tipo de serviço realizado e o valor pago. Ao finalizar os cadastros, o sistema gera um resumo completo e estatísticas do dia.

## ✨ Funcionalidades

- **Cadastro Interativo:** Inserção de múltiplos pets através de um loop de repetição (`while`).
- **Registro de Serviços:** Suporte para diferentes tipos de serviços (`banho`, `tosa`, `consulta`).
- **Cálculo Automático de Faturamento:** Soma total dos valores arrecadados no dia.
- **Média por Atendimento:** Cálculo do ticket médio por pet atendido.
- **Contagem por Categoria:** Exibição da quantidade específica de cada serviço prestado.
- **Validação de Vazio:** Tratamento caso nenhum pet seja cadastrado no dia.
